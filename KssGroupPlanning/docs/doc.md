# Документация к проекту информационной системы планирования производства промышленных изделий

## Термины

* Заказ на производство - инциализирующий документ по которому планируется документ.
* Изделие - объект производства
* Материалы - необходимые материалы для реализации изделия
* Технологическая карта производства - тех. карта производимого изделия, имеет информацию по этапам сборки и производства, а также нормативы по времени.
* Тип изделия - название шаблонного изделия
* Подтип изделия - название подтипа шаблонного изделия

## Назначение информационной системы

Данная система необходима для автоматизации производства промышленных изделий, система строит по технологическим картам этапы сборки и производства, а также обозначает время выполнения работ, а также их порядок.

Данная система позволяет наглядно посмотреть на загруженность производств, что необходимо бизнесу для планирования своих ресурсов.

Данная система позволяет получить примерное время производства изделия в случае оформления заявки в текущий день.

# Архитектура проекта

Данная система интегрирована с системой источником, благодаря чему получает актуальные данные.

Полученные данные обрабатываются, преобразовываются в ядре планировщика и сохраняется в базе данных.

Реализована авторизация и аутификация.
